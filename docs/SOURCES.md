# Источники данных для демо «Снабженец» (replay)

Проверка проведена 08.11.2026. Выход в интернет был через немецкий IP (`ipinfo.io/country` = DE): похоже, на машине включён VPN. Ещё был WebFetch с серверов в США и встроенный браузер на той же машине. Запросов немного, интервалы 1–3 с. Формы, вход, регистрация и обход капчи не использовались.

Пометки: **[проверено]** — видел сам в ответе сервера; **[архив]** — видел в снимке Wayback Machine; **[поиск]** — только из выдачи поисковика, страницу не открывал; **[не проверено]** — указана причина.

## 1. Рекомендация

1. **ЕИС берём, но срез снимаем с российского IP.** Из моего окружения zakupki.gov.ru не открылся: TLS-соединение не устанавливается, и в браузере тоже. Снимки 2026 года в Wayback показывают, что поиск по реестру контрактов и карточки контрактов отдаются без входа, обычным HTML. В карточке видны поставщик с ИНН, а также позиции с ОКПД2/КТРУ, количеством и ценой за единицу. Это ровно то, что нужно для `EisPort` в режиме replay.
2. **Реальные контракты по трём позициям я не нашёл и не проверил.** Агрегаторы закупок либо прячут данные от гостей, либо запрещают такой доступ в robots.txt. Таблицу контрактов команда заполняет сама с российского IP по готовым ссылкам из раздела 2.4. Там же есть лиды из поиска.
3. **Основной магазин — Регард (regard.ru).** У него есть все три товара, в наличии, цена лежит в JSON-LD `schema.org/Offer`. Страница отдаётся обычным HTTP-запросом без капчи и JS-заглушки.
4. **Второй магазин — НИКС (nix.ru).** Все три товара есть, цена в microdata `itemprop="price"`. На странице видна отдельная цена «за б/н юрлицам», а у филиала в Махачкале (СКФО) своя цена. Это хорошо показывает учёт региона.
5. **Комус, Ситилинк, DNS, ВсеИнструменты и Ozon не годятся для записи.** У них антибот (Qrator и аналоги) или капча уже на robots.txt. У ОфисМага JS-проверка (proof-of-work): без исполнения JS страница не отдаётся, к тому же у него нет оригинального картриджа и проектора в наличии.
6. **Коды:** картридж — КТРУ `20.59.12.120-00000002`; проектор — ОКПД2 `26.20.17.120`, КТРУ `26.20.17.120-00000001/-00000002`; бумага — ОКПД2 `17.12.14.129`, КТРУ `17.12.14.129-00000025`. Код 26.20.18 к проекторам не относится.

### 2.2 Как искать (адреса и параметры)

**Поиск по реестру контрактов 44-ФЗ:**
`https://zakupki.gov.ru/epz/contract/search/results.html`

Имена полей формы [архив, снимок 04.05.2026]: `searchString`, `morphology`, `strictEqual`, `fz44`, `contractStageList_0..3` / `contractStageList`, `contractDateFrom` / `contractDateTo` (дата заключения), `publishDateFrom/To`, `updateDateFrom/To`, `priceFromUnitGWS` / `priceToUnitGWS` (цена за единицу), `contractPriceFrom/To`, `customerPlace`, `customerPlaceCodes`, `budgetLevelsIdHidden`, `placingWayList`, `sortBy`, `sortDirection`, `pageNumber`, `recordsPerPage`.

- Поле `searchString` по подсказке формы ищет по номеру реестровой записи, ИКЗ, наименованию заказчика, номеру и предмету контракта, наименованию объекта закупки. В архиве есть запросы вида `searchString=<ИНН>`.
- **Регион заказчика** (`customerPlace` / `customerPlaceCodes`): код Чеченской Республики **не проверен**. Выбрать регион в фильтре вручную, затем скопировать получившийся URL.
- **ОКПД2/КТРУ:** отдельных полей в HTML архивной формы нет (подгружаются JS-виджетом), имена параметров **не проверены**. В поиске по планам-графикам параметр `ktruCodeNameList=<код КТРУ>` встречается [поиск]. Для контрактов надёжнее искать текстом: `searchString=CF259A` или `searchString=бумага для офисной техники`.
- Формат ссылки «контракты по ИНН поставщика» [проверено, взят с checko.ru]:
  `https://zakupki.gov.ru/epz/contract/search/results.html?morphology=on&fz44=on&supplierTitle=2020000570&sortBy=UPDATE_DATE&pageNumber=1&sortDirection=false`

**Карточка контракта** (вкладки [архив]):
- `…/epz/contract/contractCard/common-info.html?reestrNumber=<N>` — заказчик (ИНН, КПП), дата заключения, предмет, цена; блок «Информация о поставщиках»: название, ИНН, КПП, адрес.
- `…/payment-info-and-target-of-order.html?reestrNumber=<N>` — объекты закупки: наименование, ОКПД2/КТРУ, количество, единица, **цена за единицу**, сумма.
- `…/process-info.html`, `…/document-info.html`, `…/journal-version.html`, `…/event-journal.html`, `…/rss?reestrNumber=<N>`.

**Каталог КТРУ:** `https://zakupki.gov.ru/epz/ktru/ktruCard/ktru-description.html?itemId=<id>` и `…/ktruCard/commonInfo.html?itemId=<id>` [поиск]. `itemId` для наших кодов **не проверен**: найти через поиск каталога КТРУ по коду.

## 5. Риски и запасные варианты

| Риск | Что делать |
|---|---|
| ЕИС не открывается из-за VPN или зарубежного IP (так было при этой проверке) | Записывать с российского IP без VPN. Если и так не выйдет — сохранить из браузера на другой машине. Последний вариант: 1–2 карточки из Wayback с пометкой «архив», агент показывается на них |
| В ЕИС Crawl-delay 60 (по архивному robots.txt), возможен антибот | Мало страниц, пауза ≥ 60 с, либо ручное «Сохранить как». На капче остановиться, не обходить |
| В ЧР нет контрактов именно на CF259A/X или проектор | Расширить до СКФО, затем до РФ; искать по КТРУ или тексту «картридж HP 59A»; в демо честно показать регион контракта |
| Реальных контрактов пока нет, лиды из поиска не проверены | Не показывать ничего, что не открыто и не сохранено вручную. Таблицу 2.4 заполнить до 12.11 |
| Цены и наличие меняются (S1386WH уже нет в наличии) | Срез фиксируется датой; на каждую позицию держать запасную модель. Для защиты нужен один записанный срез, живые цены не нужны |
| У НИКСа региональная страница без microdata, кодировка cp1251, robots.txt в gzip | Парсер: сначала microdata, затем текст («ЦЕНА: … руб.», «за б/н юрлицам: … руб.»). Явно декодировать cp1251. Это хороший пример для правила «цена найдена в тексте страницы» (RULES.md, п. 8) |
| Регард: страница ~1 МБ (Next.js), разметка может поменяться | Брать JSON-LD `Offer`, сверять с видимым текстом «13 250 ₽». Хранить исходный HTML |
| Магазины московские, а заказчик в Грозном | НИКС-Махачкала как региональная цена; в обосновании указать, что цена включает или не включает доставку |
| Картриджи: оригинал и совместимый сильно различаются в цене (13 тыс. против ~1 тыс.), а у совместимых бывает блокировка прошивкой | В заявке требование «оригинальный»; агент отбрасывает совместимые по полю «Тип совместимости»/бренду, с причиной |
| Тип проектора в КТРУ (стационарный или портативный) не совпадает с моделью | Определиться заранее: Acer X1123HP — «портативный» (-00000002) |
| Источники дают меньше 3 цен (требование методики) | ЕИС (3–5 контрактов) + Регард + НИКС + ответы «двойников» в песочнице. Запасной магазин — ОфисМаг (бумага), сохранённый из браузера |
