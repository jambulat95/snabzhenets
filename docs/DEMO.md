# Демо на защите — сценарий показа

Защита: суббота, 14 ноября 2026. Показ — локально на ноутбуке, **работает без интернета**.
Длительность: 6–7 минут вживую. Запасной вариант — видео (раздел 5).

## 1. Подготовка (за 30 минут до выхода)

```bash
cd ~/projects/snabzhenets && docker compose up -d          # база, Redis, почта, API, воркер
curl localhost:8010/api/health                              # {"demo_mode":true,"db":"ok","redis":"ok"}
cd frontend && npm run dev                                  # интерфейс: http://localhost:5173
```

- В `.env` должно быть `LLM_REPLAY=replay_or_live`: ответы моделей берутся из записи (`data/replay/llm`), при сети недостающее спрашивается у живой модели. **Без интернета демо проходит целиком** (проверено в режиме `replay`).
- Войти: `zakupki@chesu.demo`, пароль — в `backend/demo_accounts.txt`.
- «Заявки» → **«Сбросить демо»** (≤ 5 секунд).
- Открыть заранее вкладку с этим файлом и папку с видео.
- Масштаб браузера 90–100 %, окно на весь экран, уведомления выключить.

## 3. Что сказать честно (не ждать вопроса)

- **Работает:** разбор заявки, подбор КТРУ, проверки поставщиков, сбор цен с сайтов с доказательствами, переписка, разбор писем и Excel, ответ на вопрос поставщика, методика, расчёт НМЦК, документ, журнал.
- **В демо эмулируется:** поставщики — вымышленные компании, их ответы пишет симулятор; почта — песочница; страницы магазинов и ответы моделей — записанные (поэтому демо работает без интернета).
- **Реестр контрактов ЕИС:** порт и формат готовы; [если срез записан — «срез на <дату>»; если нет — «в пилоте подключается веб-сервис ЕИС, в демо — справочник»].

## 4. Вопросы жюри — короткие ответы

| Вопрос | Ответ |
|---|---|
| Чем вы отличаетесь от Контура и калькуляторов НМЦК? | Полный цикл одним агентом: от фразы до документа, включая разбор ответов в свободной форме, и доказательство у каждой цены. Калькуляторы считают по введённым ценам; рассылки не разбирают ответы. |
| А если модель ошибётся? | Модель не считает и не решает: числа код сверяет с письмом или разметкой страницы, методику и НМЦК считает код. Сомнительное уходит человеку. Утверждает человек. |
| Законно ли брать цены с сайтов? | Открытые цены — допустимый источник по методике. Мы соблюдаем robots.txt, не обходим капчу и вход, храним снимок с датой. |
| Это не спам поставщикам? | Письма — только по конкретной заявке, с ящика учреждения, в форме официального запроса ст. 22. В демо — только песочница, это проверено тестом. |
| Персональные данные? | Работаем с реквизитами юрлиц. Перед облачной моделью ПДн маскируются; возможна локальная модель (Qwen) в контуре учреждения. |
| Почему коэффициент вариации 33 %? | Это порог однородности из методических рекомендаций (приказ № 567); параметры — в профиле, а не в коде. |
| Если поставщики не отвечают? | Напоминание через сутки; по сроку сбор закрывается и считается по тому, что есть, с фиксацией причины; можно расширить список. |
| Сколько стоит? | Модели — единицы рублей на заявку. Модель продаж — подписка для учреждения (предварительно 36–60 тыс. ₽ в год), укладывается в закупку у единственного поставщика. |
| Что дальше? | Пилот у 1–3 заказчиков, подключение веб-сервиса ЕИС и проверки контрагентов, затем регион. |

## 5. План Б

- **Что-то зависло** → «Сбросить демо», начать с «Новая заявка» (весь путь — ~2 минуты работы агента).
- **Воркер завис** → `docker compose restart worker`.
- **Нет сети** → ничего не делать: `LLM_REPLAY=replay_or_live` отвечает из записи.
- **Ноутбук не работает** → видео `~/projects/imfit_concurs/demo/snabzhenets-demo.mp4` (1:26, полный прогон без звука; перезаписать: `cd backend && uv run python scripts/record_demo_video.py`). Скопировать на флешку и в облако заранее.
- Проверка перед выходом одной командой: `cd backend && uv run python -m app.seed --reset && uv run python -u scripts/check_scenario.py` → «СЦЕНАРИЙ ПРОШЁЛ». После неё — снова «Сбросить демо».
