# «Снабженец»

ИИ-агент снабженца для бюджетных учреждений: находит поставщиков по открытым данным ЕИС, собирает цены с сайтов и по почте, разбирает ответы в любом формате и готовит обоснование НМЦК (метод сопоставимых рыночных цен, приказ Минэкономразвития № 567) с доказательством по каждой цене. Человек подтверждает спецификацию и утверждает обоснование.
